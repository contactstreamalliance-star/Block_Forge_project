# Modding

The `mods/` folder is reserved for the future BlockForge mod system.

For this pre-alpha, blocks are edited directly in `assets/blocks.json`, and textures are edited in `assets/textures/blocks/`.

The planned mod system will support:

- block packs;
- item packs;
- recipe packs;
- texture packs;
- scripts with a stable BlockForge API;
- custom mod loaders outside the Minecraft ecosystem.

## Current Rule

Keep all modding data readable. Prefer plain folders and plain files over archives when possible.
