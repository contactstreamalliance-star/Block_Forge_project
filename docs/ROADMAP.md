# Roadmap

## Pre-alpha 0.2

- Native Godot desktop version.
- Basic voxel world.
- Break and place blocks.
- Editable textures and sounds.
- In-game patch notes.
- Cleaner code separation for contributors.

## Next

- Better chunk rebuilding.
- Real inventory counts.
- Crafting screen.
- Main menu world selection.
- Mod manifests.
- More blocks, tools and survival systems.
- Cleaner modding hooks for blocks, recipes and world generation.

## Later

- Optional community multiplayer research only if the local game is already solid.
- No forced online mode.
- No official default server baked into the project.
