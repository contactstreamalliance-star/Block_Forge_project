# Asset Sources

BlockForge Alpha must only use original assets or assets with a clear open license.

## Current Project Assets

- Block textures in `assets/textures/blocks/` are editable prototype assets.
- UI images in `assets/ui/` are prototype assets.
- Audio files in `assets/audio/` are prototype chiptune sounds and music.

## Rules

- Do not use Minecraft textures, sounds, code, logos, names or protected branding.
- Keep license notes close to imported assets when third-party assets are added.
- Prefer CC0, MIT, Apache-2.0 or similarly clear licenses for reusable assets.
- Document every third-party asset source in this file or in `assets/licenses/`.

## Future Assets

When the visual direction improves, replace placeholders with original BlockForge assets that fit a local voxel sandbox: blocks, tools, creatures, UI and retro audio.
