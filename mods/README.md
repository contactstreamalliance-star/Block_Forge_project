# Mods

The `mods/` folder is reserved for future BlockForge Alpha mod packs.

For this pre-alpha, edit these files directly:

- `assets/blocks.json` for block definitions.
- `assets/recipes.json` for recipes.
- `assets/worldgen.json` for world generation.
- `assets/textures/blocks/` for block textures.
- `assets/audio/` for sounds and music.

Future mods should stay independent from Minecraft modloaders and should use BlockForge's own open file formats.
