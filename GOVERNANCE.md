# Governance

BlockForge Alpha starts as a small experimental open source voxel sandbox.

Maintainers should protect the project's open source status, keep the game focused on local solo-first voxel play, review pull requests carefully and keep the project legally independent from Minecraft.

The project should stay simple, moddable and readable. Online features, if they ever arrive, must stay optional and must never require hidden connection targets, account requirements or hardcoded personal information.
